# Agent guidance

- This repository is a reusable Drupal project template. Keep documentation and configuration generic, and do not add client-specific identifiers or secrets.
- Read `README.md` for local development and AI workflow instructions. Run `rig init` for each generated project before `rig up`; use `ddev` for project commands.
- Follow the repository's Drupal coding standards and quality checks configured in `phpcs.xml`, `phpstan.neon`, and `grumphp.yml`.
